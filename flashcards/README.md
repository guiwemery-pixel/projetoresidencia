# Flashcards

App de flashcards de medicina com revisão espaçada (FSRS), Quick Review, pontos fracos por tema,
geração de cards a partir de PDFs com IA e importação do Anki com o histórico de revisões.

- **Abrir:** `index.html` direto no navegador, ou `/flashcards/index.html` no Projeto Residente publicado.
- **Documentação completa:** [`../docs/FLASHCARDS.md`](../docs/FLASHCARDS.md)
- **Testes:** `npm run test:flashcards` (unitários) e `npm run test:flashcards:e2e` (navegador), na raiz do repositório.
